# Product Principles for Every Future Decision

## Purpose
The standing 10-question gate every future feature proposal must pass before implementation. Referenced directly by [CLAUDE.md](../CLAUDE.md) (Decision-Making Framework).

## The Ten Questions

Before implementing any new feature, ask:

1. Does this reduce or increase cognitive load?
2. Does it strengthen the organization's knowledge?
3. Does it integrate with existing business objects?
4. Does it respect permissions and security?
5. Can it be discovered through search?
6. Can it participate in automation?
7. Is it auditable?
8. Is it accessible?
9. Does it work responsively?
10. Will it still make sense when the platform is ten times larger?

**If the answer to any of these is "no," the feature should be redesigned before implementation.**
