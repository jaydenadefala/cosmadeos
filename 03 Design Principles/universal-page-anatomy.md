# Universal Page Anatomy & Object Header Standard

> Reference note — rolls up into [04 Enterprise Architecture/enterprise-information-architecture.md](../04%20Enterprise%20Architecture/enterprise-information-architecture.md).

## Universal Page Anatomy

Every page follows the same hierarchy. This anatomy never changes:

`Top Navigation → Workspace Sidebar → Breadcrumbs → Page Header → Context Toolbar → Primary Content → Related Information → Activity Timeline → Footer Actions (if required)`

## Universal Detail Page

Every major business object (Employee, Customer, Invoice, Vendor, Campaign, Research, Knowledge Article, Contract, SOP) uses the same layout:

`Header → Overview → Related Information → Documents → Comments → Activity → History → Automation → AI Insights`

Users immediately know where to look, regardless of object type.

## Object Header Standard

Every object page begins with:
- Object Icon
- Object Name
- Status
- Owner
- Department
- Last Updated
- Quick Actions
- Share
- Favorite
- AI Summary
- Health Indicator
- Relationship Count
- Approval Status

This standard applies everywhere — no department or object type gets a custom header layout.

## Action Placement

**Primary Action** — top right (e.g., Create Employee, New Campaign, Approve Invoice).

**Secondary Actions** — dropdown. Never scatter actions randomly across the page.
