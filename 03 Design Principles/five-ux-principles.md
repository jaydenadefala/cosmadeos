# Five UX Principles

> Reference note — rolls up into [02 Product Philosophy/product-philosophy.md](../02%20Product%20Philosophy/product-philosophy.md) and [11 UX System/enterprise-quality-checklist.md](../11%20UX%20System/enterprise-quality-checklist.md).

## Principle One — Speed Over Decoration
Employees use this system every day. Animations should never delay work. Navigation should be instant. Search should feel immediate. Buttons should respond instantly.

## Principle Two — Context Over Navigation
Never make users open five pages to complete one task. Instead, related information should exist together: Customer → Contracts → Invoices → Meetings → Timeline → Comments → Tasks all live in one place.

## Principle Three — Progressive Disclosure
Don't overwhelm users. Show: Most important → Important → Advanced → Expert. Hide advanced configuration until requested.

## Principle Four — Consistency
Every object behaves similarly — Employee, Company, Invoice, Campaign, Knowledge Article, Research Project, Vendor, Customer all use the same interaction language. See [04 Enterprise Architecture/enterprise-information-architecture.md](../04%20Enterprise%20Architecture/enterprise-information-architecture.md) (Universal Object Model).

## Principle Five — Confidence
Every interaction should reassure users: "Saving...", "Saved.", "Approved.", "Invoice sent.", "Campaign published.", "Automation completed." Users should never wonder whether something worked.
