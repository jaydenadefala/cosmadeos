# Implementation Series Overview

## Purpose
Track the status of each Implementation Series volume — the sequence that converts the enterprise blueprint into a production-ready engineering specification, executable systematically by designers, backend engineers, and QA teams.

## Vision
Five implementation volumes, each depending on the one before it, converting the Foundation-level architecture into buildable specification.

## Philosophy
Phase-based execution: do not skip ahead to a later volume's concerns while a prior volume is still open — see [CLAUDE.md](../CLAUDE.md) (Phase-Based Execution Rules).
