# Enterprise Quality Checklist

## Purpose
The mandatory gate every feature passes before release. No feature is considered complete until it passes every applicable section.

## User Experience
- Is the workflow intuitive?
- Is terminology consistent?
- Are primary actions obvious?
- Can common tasks be completed efficiently?

## Design
- Uses approved design tokens.
- Uses shared components.
- Matches workspace identity.
- Responsive across supported devices.

## Accessibility
- Keyboard accessible.
- Screen-reader friendly.
- Color contrast compliant.
- Error messaging accessible.

## Performance
- Meets performance budgets.
- Handles large datasets.
- Optimizes network usage.
- Avoids unnecessary re-renders.

## Security
- Permission-aware.
- Audit logging implemented.
- Sensitive data protected.
- Export permissions respected.

## Reliability
- Handles loading states.
- Handles empty states.
- Handles error states.
- Handles offline scenarios where applicable.

## Intelligence
- Search indexing configured.
- AI integration evaluated.
- Relationships established.
- Activity timeline enabled.
