# Accessibility & Performance Standards

> Reference note — rolls up into [11 UX System/enterprise-quality-checklist.md](enterprise-quality-checklist.md).

## Performance Standards

Performance is a product feature. Target expectations:
- Initial application shell loads quickly on standard broadband.
- Page transitions feel instantaneous where data is already available.
- Search returns responsive incremental results.
- Large datasets use virtualization, pagination, or progressive loading.
- Background synchronization should not block interaction.

Performance budgets should be defined and monitored during implementation.

## Accessibility Interaction Standards

Every interaction must be usable with: keyboard only, screen readers, high zoom levels, reduced motion preferences, high-contrast themes (future). Focus order must be logical and visible. No interaction should depend solely on color.

Platform-wide accessibility target: WCAG 2.2 AA (per [04 Enterprise Architecture/enterprise-information-architecture.md](../04%20Enterprise%20Architecture/enterprise-information-architecture.md), Cross-Cutting UX Standards).
